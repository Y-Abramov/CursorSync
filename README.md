# CursorSync — Отслеживание курсора

Модуль для Топоматик Robur. Синхронизация курсора между видом плана и продольным профилем.

## Возможности

- Синхронизация курсора между планом и продольным профилем трассы (дороги, железные дороги)
- Синхронизация курсора между планом и профилем ветки инженерной сети
- Синхронизация курсора между планом и редактором профиля сечения структурной линии
- Настраиваемые цвета и размеры маркеров

## Совместимость

Работает во всех продуктах Robur. Дисциплина-специфичные команды (трасса, ветка сети) актуальны там, где есть соответствующие объекты; профиль сечения структурной линии доступен везде.

| Продукт | Поддержка |
|---------|-----------|
| Топоматик Robur — Автомобильные дороги | ✓ |
| Топоматик Robur — Изыскания | ✓ |
| Топоматик Robur — Железные дороги | ✓ |
| Топоматик Robur — Искусственные сооружения | ✓ |
| Топоматик Robur — Инженерные сети | ✓ |
| Топоматик Robur — Генеральные планы | ✓ |

**Минимальная версия Robur:** 16.0.62.12

## Установка

Через менеджер модулей **ABR \| Библиотека модулей** (требуется модуль [abr-modules](https://github.com/Y-Abramov/AbrModules)):

1. Открыть **ABR → Модули → Управление модулями**
2. Найти **CursorSync** в каталоге
3. Нажать **Установить** и перезапустить Robur
